# Simple Snake Game

A classic snake game built with Python and Tkinter. Control the snake to eat apples and grow longer while avoiding walls and yourself.

## Features

- Simple and intuitive controls
- Score tracking
- Game over detection with restart option
- Clean, retro-style graphics

## How to Run

1. Make sure you have Python installed (version 3.6 or higher)
2. Run the game with: `py main.py` or `python main.py`

## Controls

- **Arrow Keys** or **WASD** to move the snake
- **Space** to restart after game over

## Game Rules

- Eat red apples to grow and increase your score
- Avoid hitting the walls or your own tail
- The game ends when you collide with an obstacle
- Press space to restart and try for a higher score

## Requirements

- Python 3.6+
- Tkinter (usually included with Python installations)

Enjoy the game!
